## Sobre o trabalho

O EstágioCheck é um sistema web para registro de presença e gerenciamento de estágios supervisionados de Enfermagem. Ele foi feito com Angular, .NET e PostgreSQL/Supabase. O sistema faz check-in e check-out com geolocalização e foto, gerencia turmas, rodízios e unidades de saúde e cuida do acompanhamento formativo, das irregularidades, dos certificados e da auditoria.
